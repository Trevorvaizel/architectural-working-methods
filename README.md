# Selected architectural methods

Three reusable methods from Trevor Richard’s working library for architectural image direction and spatial presentation. They expose the questions, source rules, operations and review steps behind the work shown in the capabilities portfolio.

## Start with the task

| Task | Method | Status |
|---|---|---|
| Direct or revise a still image while keeping the project legible and consistent | [Architectural render credibility](skills/architectural-render-credibility-v1/SKILL.md) | Project-developed and revised through Pin-Point render studies |
| Turn an actual architectural model into a composed browser presentation | [Architectural cinematic maquette](skills/architectural-cinematic-maquette/SKILL.md) | Applied to Resort Residence; adapted to Pin-Point |
| Turn an intended interior feeling into explicit perception, light and material decisions | [Interior rendering physics](skills/vaizel-interior-rendering-physics/SKILL.md) | Experimental v0.1 |

Read [SKILLS.md](SKILLS.md) for operations, dependencies and evidence. [PROVENANCE.md](PROVENANCE.md) distinguishes project-developed methods from the changes made for this portable collection.

## Use

Read the chosen `SKILL.md` and keep its reference folder beside it. In an agent host supporting filesystem skills, install the complete method directory according to that host’s instructions. In another environment, supply the method and its referenced files as task guidance. The optional `agents/openai.yaml` file supplies display metadata for compatible hosts.

These are workflow instructions, not rendering software or a hosted service. Still-image work needs an image inspection/editing tool and project sources. The maquette method needs model preparation and browser development tools such as Blender and Three.js. Those tools, project files, generated images and service credentials are not included.

Use one rendering method as the governing contract for a task. Render credibility normally returns revisions to the original design controller; Interior Physics uses an approved successful parent for bounded calibration. They are distinct operating approaches, not interchangeable revision instructions. The credibility score is an internal review heuristic, not a measured guarantee of physical or geometric accuracy.

## Scope

The collection shares methods rather than client models, drawings, images or conversations. Interior Physics remains an experimental method; the other two methods carry project-derived review rules.
